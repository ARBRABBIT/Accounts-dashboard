# GLC design system
The source of truth is src/app/globals.css; /design-system provides the visual reference. Derived from Figma GLC Re-Design: Farmland Revenue (node 8119:11220), Accounts Dashboard (node 8119:2555), and Revenue Management.

## Foundations
Plus Jakarta Sans. Page titles 28px/1.1 weight 600; section/card headings 22px-34px/32px-40px weight 600-800; supporting text 18px weight 500; body 14px/20px; labels 10.5px-11px weight 600-700 with letter tracking; hero metrics 52px-76px weight 800. Spacing follows a 4px scale, preserving Figma geometry.

Colors: canvas #f8f9fa, surface #ffffff, subtle #f9f9fa, ink #1a1c1d, muted #5e5e63, label #64748b, brand #2780c4, action #3d93d1, revenue #00609a, line #e5e5ea, supporting #524f4f, return-status #3c78b9. Use text-brand, bg-surface, border-line and equivalent semantic classes.

Radii: main canvas #f8f9fa without extra enclosing layer, cards 24px - 26px, panels 16px, tables 28px, action pills 9999px.

## Components
- Button: primary, secondary, icon variants, native disabled and focus states.
- BackButton: standardized 40px circular action pill (`h-10 w-10 rounded-full hover:bg-black/5 active:scale-95`) with 24px Lucide ArrowLeft (2px stroke #1D1D1F) and optical `-mt-1` alignment with 28px page titles and breadcrumb bars, used consistently across all header navigation (/subscription, /farmland-services).
- PillDropdown: accessible pill dropdown trigger for timeframe selectors and filter dropdowns with 'light' and 'bordered' variants, plus optional searchable filtering input (`searchable`, `searchPlaceholder`).
- Asset: local original Figma SVGs and images at explicit dimensions.
- Modal: native dialog, focus trapping, Escape dismissal, accessible heading and close control.
- Table, TableHead, TableCell, Pagination: unified across all screens (/farmland-services, /subscription, /revenue-management, /farmland-revenue) with rounded-[24px] surface, subtle #FAFBFD uppercase header, px-6 sm:px-8 py-4 sm:py-5 cell padding, right-aligned numeric metrics, rounded-full #2780C4 action buttons, and standardized 16px radius pagination controls.
- AccountsSidebar: persistent desktop navigation sidebar with GLC logo, active route highlighting (Dashboard, Revenue Management), quick action icons, and user avatar.
- AccountsHeader: search bar with magnifier icon, notification trigger with unread badge, and configurable title hierarchy.
- PlatformRevenueCard: hero revenue presentation featuring Platform Revenue Run-Rate (₹8.30 Cr monthly operating volume, 98.4% enterprise renewal rate, and ₹3.20 Cr agent payouts) with multi-slide indicators and period selector.
- CommissionChartCard: stacked monthly bar chart featuring Paid gradient and Pending diagonal hatch patterns with interactive tooltips and inside Y-axis labels.
- PlatformCollectionsCard: smooth spline waveform line chart depicting 7-day platform collections velocity across Subscriptions, Services, and Verification (₹12.45 Cr weekly volume with 99.2% on-time settlement efficiency).
- AccountsCreditsCard: semi-circular radial speedometer gauge with active gradient ticks, pointer arrow, and dual credit breakdown metrics.
- FeaturedRevenueCard: primary vertical card showcasing Land Sales Revenue (₹18.2M), month-over-month trend badge (+14%), and interactive breakdown modal.
- SecondaryRevenueCard: 2x2 bento metric cards (Pool Buying, Subscriptions, Farmland Services, External Verification).
- RecentActivityTable: transaction activity table with lead avatars, status badges, timestamps, and interactive detail modals.
- AgentCommissionCard: 28px radius agent card matching Figma spec, featuring avatar, agent ID, Region, District/Area, Land ID, Date, Amount with blue text gradient (#2780C4 to #154B73), uppercase status badge (Paid / Pending), and 54px rounded-full #3D93D1 View action button.
- AgentCommissionTable: unified GLC table primitive featuring rounded-24px surface, subtle #FAFBFD uppercase header, Farmland ID pill as first column, agent avatar & name, region, district/area, date, right-aligned gradient amounts, status pill indicators (Paid / Pending), rounded-full #3D93D1 View action button, and integrated Pagination footer.
- CommissionDetailsView: dedicated full-page drilldown view opened when clicking "View" on an agent, featuring interactive breadcrumbs (Commission Management > Commission Details), 3-card top bento grid (Profile Card with online indicator and badges, Contact Information with Agent ID & Phone, Assigned Territory with Region, District & Mandal), Revenue Breakdown by Location section with search by Land ID, calendar button, unified table view (Farmland ID with photo thumbnail, Customer, Location, Sale Value, Earned, Pending, Status, Action), and Pagination footer.
- FloatingNavigation: bottom navigation pill with a dedicated "Pages" popover modal listing all created screens for seamless site-wide navigation.
- FigmaComments (CommentOverlay, CommentPin, CommentCard, CommentProvider): Figma-like contextual commenting system. Features teardrop numbered pins with container-relative anchoring, hotkey toggle ('C'), interactive draft drop anywhere on the screen, edit and delete controls with confirmation, route-scoped isolation (comments appear only on the page they were created), and browser LocalStorage persistence across page reloads.

## Behavior
GSAP entrance uses 450ms duration, 16px y-offset, 80ms stagger, power2.out, and is disabled for users preferring reduced motion. Interactive controls support keyboard navigation and visible focus rings (3px brand outline with 4px offset). Responsive layouts adapt from 1440px desktop down to mobile viewports.
